# Company Website Clone

A responsive company website landing page built from scratch using HTML and CSS.

## Features

- Responsive navigation bar
- Hero section with call-to-action buttons
- Responsive dashboard visual
- Company trust/logo section
- Feature cards
- Product section with payment card visual
- Customer testimonials
- Call-to-action section
- Responsive footer
- Hover and focus states
- Responsive layouts for desktop, tablet, and mobile screens

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Transitions
- CSS Transforms
- Pseudo-elements
- Responsive Design

## Installation

1. Clone the repository:

```bash
git clone https://github.com/sktawfiq/company-website-clone.git
```

2. Open the project folder:

```bash
cd company-website-clone
```

3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.
